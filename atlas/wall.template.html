Same starting conditions. Every one of them.

Each band is one world's entire history. They were run from an identical configuration — same rules, same parameters, same resource statistics — and differ only in which random draws they got. Nothing here was designed to diverge.

How to read a band

bar height — population, on one scale shared by every world
color — energy_gini, also on a shared scale
red column — a drawdown of more than 35% below the running peak

What the marks do and do not claim

The wall draws every drawdown it was given. Only the number above says whether there are more of them than a population with this same volatility produces by chance. A picture that showed the marks without the verdict would be claiming significance the data has not earned.
